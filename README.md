# 餐饮点餐系统小程序 PHP+uniapp

餐饮点餐小程序，采用 Uniapp 前端 + PHP 后端开发，可打包微信小程序，支持单店、多门店使用，适合中餐、奶茶、快餐、火锅等各类餐饮门店。
顾客端微信一键授权登录，桌码扫码自助点餐，浏览菜品分类、规格、套餐，加入购物车在线支付；支持堂食、外卖、到店自提，内置优惠券、会员积分、订单查询，消费记录随时查看。
PHP 管理后台可维护菜品分类，菜品上下架、图片上传、套餐设置；支持桌台管理、订单实时接收、退款操作、后厨小票打印，会员管理、营销活动配置，自动统计门店营收数据。
